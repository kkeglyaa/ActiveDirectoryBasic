# ActiveDirectoryBasic
базовая настройка AD на WB
1. Устанавливаем образ Windows Server на WB
2. Делаем базовую настройку Windows Server

 <img width="441" height="292" alt="image" src="https://github.com/user-attachments/assets/3c923d15-e268-4894-9c43-ffe04b0d1636" />
 
 настраиваем имя домена, имя контроллера домена а так же IPv4 адрес и DNS сервер ( для корректной работы указываем 127.0.0.1 в качестве предпочитаемого DNS сервера)
4. Создаем объекты AD
создаем учетные записи пользователей и группы безопасности, для разграничения доступа к ресурсам
подразделения:
HR, IT, Management, Groups.
в подразделении Groups:
HR_users, IT_users, Management_users. Данные группы были предназначены для централизованного управления доступом пользователей к сетевым ресурсам
В соответствующих подразделениях домена были созданы учетные записи пользователей. В дальнейшем каждый пользователь был назначен в соответствующую группу безопасности своего отдела.

Настройка прав доступа на файловом уровне (NTFS + общие папки)
создаем структуру папок \Shares 
внутри нее создаем подкаталоги HR, IT, Management
для каталога Shares был настроен общий сетевой доступ, который позволяет пользователям домена подключаться к ресурсам через сеть 
Настройка NTFS 
для папки HR предоставляем доступ группе HR_users
для папки IT предоставляем доступ группе IT_users
для папки Management предоставляем доступ группе Management_users
Принцип: доступ был предоставлен не отдельным пользователям, а группам безопасности, каждая группа соответствует своему отделу, пользователи получают доступ автоматически через членство в группе 
В результате: каждая группа имеет доступ только к относящейся им папке ( пример HR для HR_users )

Так же стоит убрать наследование прав 
для каждой папке была выполнена операция: открытие свойстваЮ вкладка безопасность, дополнительно, отключено наследование прав доступа( преобразовать унаследованные разрешения в явные)
для того, чтобы убрать лишние права, избежать автоматический доступ всех отделов ко всем папкам, задать уникальные права для каждой папки отдела ( проще говоря, чтобы в папке IT не было доступа для HR_users, а был доступ только у IT_users)

Вывод: была развернута и настроена доменная инфраструктура на базе Windows Server с использованием служб Active Directory. В результате была реализована модель управления доступом RBAC ( Role-Based Access Control )
